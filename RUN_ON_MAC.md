# RC3: короткая проверка упаковки на Mac

**Основные вычисления уже подтверждены запуском 18 октября. Повторять PCA сейчас не требуется.**

1. Распакуйте ZIP RC3 в новую папку `MDPI_Data_GCF_RELEASE_CANDIDATE_RC3`.
   Не заменяйте старый проект; не переносите и не удаляйте его папку `runs`.
2. Откройте в новой папке `MDPI_Data_GCF.Rproj`. В RStudio используйте **Terminal**.
3. Из корня новой папки выполните:

```bash
Rscript tools/check_release.R
```

Ожидаемая последняя строка:

```text
PACKAGING CHECK PASS - no PCA, no new analysis. Results: ...
```

Проверка считает только контрольные суммы, разбирает R-синтаксис и тестирует запись журнала/манифеста
на временных служебных файлах. Пациентские матрицы не анализируются; PCA и проекции не выполняются.
Новых R-пакетов не требуется. Если появляется ошибка, пришлите её текст, не исправляйте исходные числа.

4. Для передачи результата выполните из той же папки:

```bash
zip -r MDPI_Data_RC3_packaging_check.zip runs
```

Нужен только этот ZIP. Внутри `runs/PACKAGING_CHECK_...` должны быть `PACKAGING_CHECK_PASS.txt`,
`CHECK_LOG.txt`, `sessionInfo.txt`, `RUN_SHA256.csv`.

## Полное воспроизведение — отдельная возможность

`Rscript run_all.R` по-прежнему воспроизводит всё исследование из нормализованных CSV.
Для текущего упаковочного исправления оно **не является обязательным первым шагом**: числовые
R-модули, входы и контрольные таблицы не менялись. Все дальнейшие полные прогоны используют
исправленный финализатор: окончательный журнал и PASS-флаг включаются в манифест до его проверки.

## Необязательный Quarto

После полного научного прогона можно выполнить `quarto render analysis/report.qmd --to html`,
если установлены Quarto и `knitr`. Верифицированный HTML не заявляется; для числовых результатов
и проверки RC3 этот шаг не нужен.

Этот кандидат не публиковать автоматически: сначала завершаются авторские декларации и лицензии.
